# JobStart

JobStart is a full stack job portal built to help users search and apply for jobs easily. The project allows users to explore different job opportunities, filter jobs based on preferences, and post jobs through a clean and responsive interface.

I built this project to improve my understanding of full stack development and to get hands-on experience with frontend, backend, authentication, API integration, and database management in a real-world style application.

---

## Features

* User authentication using Auth0
* Search jobs using keywords
* Filter jobs by category and salary range
* Post new jobs
* Apply to jobs
* Save/Favorite jobs
* Dynamic job details page
* Responsive UI for different screen sizes
* Protected routes and backend authentication
* MongoDB database integration

## Installation

### Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_LINK
```

### Frontend Setup

```bash
cd client
npm install
npm run dev
```

### Backend Setup

```bash
cd server
npm install
npm start
```

---

## Environment Variables

Create a `.env` file inside the server folder and add the following:

```env
PORT=
MONGO_URI=
CLIENT_ID=
SECRET=
ISSUER_BASE_URL=
BASE_URL=
CLIENT_URL=
```
